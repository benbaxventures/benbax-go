# Benbax Go User and Presentation Guide

**Website:** [https://benbaxco.com](https://benbaxco.com)

This guide explains how Benbax Go works, how to get the correct app, and how to complete the first setup. It is written for customers, drivers, delivery riders, administrators, and presentation attendees.

> **Important:** Download Benbax Go only from the official website: `https://benbaxco.com`. Check the address bar before downloading or entering your password.

## 1. Benbax Go at a Glance

Benbax Go is one platform with three connected parts:

| Part               | Main users                                   | What it does                                                                                        |
| ------------------ | -------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Client App         | Customers                                    | Requests rides or deliveries, views prices, follows job progress, and receives updates.             |
| Driver / Rider App | Drivers and delivery riders                  | Receives available jobs, accepts work, uses navigation, updates job status, and records completion. |
| Admin Web App      | Platform administrators and operations staff | Monitors activity, manages users and partners, reviews jobs, and supports daily operations.         |

The three parts share the same platform service. A client request appears to the operations system. The system sends suitable work to an available driver or rider. The client can then see progress while the administrator can oversee the process.

### Simple example

1. A client enters a pickup point and destination in the Client App.
2. Benbax Go creates the request and looks for an available partner.
3. A driver or rider sees the offer in the Driver / Rider App and accepts it.
4. The driver or rider completes the job and updates its status.
5. The client receives progress updates, and the administrator can monitor the job in the Admin Web App.

## 2. Before You Start

Have the following ready:

- A smartphone for the Client App or Driver / Rider App.
- A reliable internet connection, such as mobile data or Wi-Fi.
- A working phone number or email address, if requested during registration.
- Location services enabled when using maps, pickup, delivery, or dispatch features.
- Camera access for identity or document checks, if the Driver / Rider App requests it.
- Your administrator login for the Admin Web App.

## 3. Get the Correct Benbax Go App

The official website is the starting point for all Benbax Go applications.

### Client App

Use the Client App if you request a ride or delivery.

1. Open Chrome, Safari, or another trusted browser on your phone.
2. Enter `https://benbaxco.com` in the address bar.
3. Open the **Client App** or **Customer App** section.
4. Read the app description and confirm that it is the customer app.
5. Select **Download** or the download link provided on the website.
6. Wait for the download to finish.
7. Open the downloaded file and follow the installation instructions.
8. Open the installed app and continue to [First-Time Setup](#5-first-time-setup).

> **Note:** Do not use the Driver / Rider App to request a ride or delivery. It is for approved drivers and delivery riders.

### Driver / Rider App

Use the Driver / Rider App if you accept and complete rides or deliveries for Benbax Go.

1. Open a trusted browser on your phone.
2. Enter `https://benbaxco.com` in the address bar.
3. Open the **Driver App**, **Rider App**, or **Partner App** section.
4. Confirm that the app is intended for drivers and delivery riders.
5. Select **Download** or the download link provided on the website.
6. Wait for the download to finish.
7. Open the downloaded file and follow the installation instructions.
8. Open the installed app and sign in or complete partner registration.

> **Warning:** Do not install an APK sent through an unknown message, social media post, or unofficial website. Ask the Benbax Go administrator for help if you cannot find the correct official download link.

### Admin Web App

Administrators do not need to install a mobile APK.

1. Open a current web browser on a computer, tablet, or phone.
2. Go to `https://benbaxco.com`.
3. Select the **Admin Web App** or **Admin Login** link on the official website.
4. Enter your administrator username, phone number, or email and password.
5. Complete any additional security check, such as a verification code, if shown.
6. Keep the admin link private and sign out when you finish on a shared device.

> **Note:** The exact admin page address may change as the website is updated. Use the admin link published on `benbaxco.com` instead of guessing a URL.

## 4. Android Download and Security Warning

### Why Android shows a warning

Android may display messages such as:

- "File might be harmful."
- "For your security, your phone is not currently allowed to install unknown apps from this source."
- "Install unknown apps."

This warning appears because the app is downloaded directly from `benbaxco.com` rather than installed through the Google Play Store. Android treats a website download as an outside source until you approve it.

The warning is a safety check. It does not automatically mean that the Benbax Go file is unsafe. A Benbax Go APK downloaded from the official `https://benbaxco.com` website is the approved source for the website distribution.

> **Warning:** Continue only when the browser address is exactly `benbaxco.com` and the connection uses `https://`. Cancel the installation if the file came from another domain or an unexpected message.

### Install the Client or Driver App on Android

Android menu names differ between phone brands and Android versions. The wording may be **Allow from this source**, **Install unknown apps**, or **Install anyway**.

1. Download the correct app from `https://benbaxco.com`.
2. Tap the download notification, or open the file from **Downloads**.
3. If Android shows a warning, read it and confirm that the file came from `benbaxco.com`.
4. If prompted, tap **Settings**.
5. Select the browser you used to download the file, such as Chrome.
6. Turn on **Allow from this source**.
7. Return to the downloaded file.
8. Tap **Install anyway** or **Install**.
9. Wait for the installation to finish.
10. For extra safety, return to the same setting and turn **Allow from this source** off after installation.
11. Open the Benbax Go app and complete setup.

If the warning still appears, do not repeatedly approve it. Confirm the website address, check that the download completed, and contact the platform administrator.

### iPhone and iPad users

Do not try to install an Android APK on an iPhone or iPad. Use the iOS download option provided by Benbax Go, if available, or follow the installation instructions shown on the official website.

## 5. First-Time Setup

### Client App setup

1. Open the Client App.
2. Select **Create account** or **Register**.
3. Enter the requested name, phone number or email, and password.
4. Enter the verification code if one is sent to you.
5. Read and accept the terms and privacy information.
6. Allow **Location** access when asked. This helps the app find your pickup point and show nearby service.
7. Allow **Notifications** so you can receive request, driver, payment, and delivery updates.
8. Check that your pickup location is correct.
9. Enter the destination and any useful instructions.
10. Review the service type, price estimate, and payment option.
11. Tap **Request**, **Book**, or the equivalent action shown in the app.
12. Watch the request status and follow the instructions in the app.

> **Note:** You can usually change permissions later in your phone's **Settings > Apps > Benbax Go > Permissions**. The wording can differ by phone.

### Driver / Rider App setup

1. Open the Driver / Rider App.
2. Select **Sign in** if your account already exists, or select **Register** if new partner registration is available.
3. Enter the requested personal and contact information.
4. Complete identity, vehicle, or document checks when requested.
5. Allow **Location** access. Select **Allow all the time** or **Allow in background** when the phone offers that choice and the app requires it for active jobs.
6. Allow **Notifications** so new job offers and status messages can reach you.
7. Allow **Camera** access if the app uses the camera for identity validation or document capture.
8. Add or confirm vehicle and service information, if requested.
9. Review the home screen and confirm that your account is approved or ready for work.

#### Go online and offline

- Tap **Go Online** when you are ready to receive jobs.
- Keep location services, mobile data, and notifications on while working.
- Review each offer before accepting it.
- Follow the pickup, ride, or delivery steps shown in the app.
- Update the job status at the correct time, such as **Accepted**, **Arrived**, **Picked up**, or **Completed**.
- Tap **Go Offline** when you are finished or do not want new offers.

> **Warning:** Background location can use more battery. Keep the phone charged and do not use the app while driving. Follow local road safety laws.

### Admin Web App setup

1. Open the Admin Web App in a browser.
2. Sign in with the administrator account provided by the platform owner.
3. Complete any security verification.
4. Review the dashboard cards, alerts, and current activity.
5. Use the main navigation to view users, drivers or riders, requests, rides, deliveries, payments, and support items available to your role.
6. Open a record to review its details before making a change.
7. Use approved actions to update account status, review documents, monitor jobs, or respond to support issues.
8. Sign out when finished, especially on a shared or public computer.

> **Warning:** Give each administrator only the access needed for their role. Never share an admin password or leave an admin session open on an unattended device.

## 6. Everyday Use

### For clients

- Check the pickup and destination before confirming a request.
- Keep notifications enabled while a ride or delivery is active.
- Follow the live status in the app.
- Use the in-app support option or the approved support contact if there is a problem.
- Keep payment details and passwords private.

### For drivers and riders

- Check your network and battery before going online.
- Accept only work you can complete safely.
- Confirm pickup and destination details before starting.
- Update status promptly so the client and admin team see accurate information.
- Use the camera only for the requested identity, document, or proof-of-completion step.
- Record delivery proof when the app requests a photo, signature, or note.

### For administrators

- Review the dashboard regularly for new requests, alerts, and exceptions.
- Check user and partner records before changing account status.
- Monitor jobs that remain pending or appear delayed.
- Protect personal, location, payment, and identity information.
- Record important operational actions according to your organization's process.

## 8. Quick Troubleshooting

### The app will not download

- Check that you are using `https://benbaxco.com`.
- Confirm that your internet connection is working.
- Make sure the phone has enough free storage.
- Try the download again in a current browser.
- Ask an administrator to confirm that the app link is active.

### Android will not install the app

- Confirm that you downloaded the correct Client or Driver / Rider APK.
- Follow the **Allow from this source** steps for the browser used to download it.
- Check that the file finished downloading.
- Remove an incomplete download and download it again from the official website.
- Do not install a file from a different website or message.

### Location or map features do not work

- Turn on the phone's Location service.
- Give Benbax Go the location permission it needs.
- For driver and rider work, allow background location if requested.
- Move outside or near a window if GPS signal is weak.
- Check mobile data or Wi-Fi.
- Restart the app after changing a permission.

### Notifications do not arrive

- Turn on notifications for Benbax Go in phone settings.
- Turn off battery restrictions for the app if they stop background updates.
- Check that the phone is not in **Do Not Disturb** mode.
- Confirm that the app is signed in to the correct account.

### The app is slow or behaves unexpectedly

- Close and reopen the app.
- Check for a new version on `https://benbaxco.com`.
- Restart the phone.
- On Android, open **Settings > Apps > Benbax Go > Storage** and clear the cache. Do not clear app data unless you know your login details or support tells you to do so.
- Check your internet connection.

### The admin page does not open

- Confirm that you are using the admin link published on `https://benbaxco.com`.
- Refresh the page or try a current browser.
- Check your internet connection.
- Confirm that your administrator account is active.
- Contact the platform owner if your password or access has expired.

## 9. When Asking for Support

Include:

- Which app you used: Client, Driver / Rider, or Admin Web App.
- Your phone or browser type and the app version, if visible.
- What you were trying to do.
- The exact message shown on screen.
- The approximate time the problem occurred.

Never send a password, full card number, one-time verification code, or identity document through an unapproved channel.
